Privacy

Aniyaa is a local Android client. It does not create an account and it does not sync bookmarks to an Aniyaa server, because there is not one.

What the app stores on the phone

Search history, saved searches, bookmarks, theme, lock PIN, preferred torrent app, and catalog mirror URLs. You can export or reset that data from Settings.

What the app sends on the network

Catalog requests to nyaa.si, sukebei.nyaa.si if you enable it, or a mirror you configure. Magnet links and .torrent files are handed to the torrent app you choose. Aniyaa does not operate that download.

Optional protections

App lock (PIN or biometrics), hide screenshots, and hide from recents are local flags. They do not hide traffic from your network.

This website

The site is static files. Theme preference is saved in your browser’s localStorage. Latest-release info is requested from GitHub’s public API and cached in sessionStorage. QR codes are generated by a third-party image API using the APK URL. GitHub and that API see the request the same way any public website would.
